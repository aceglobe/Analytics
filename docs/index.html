Overview

What’s in the repository

Course materials

The repository README describes the collection as public course material that includes sample hands-on labs, course outlines, slides, and related resources.

Learning flow

The materials are organized into module folders, making it easy to present the course as a guided learning pathway from foundations through advanced analytics and AI.

GitHub Pages ready

This site is built as a static page, so you can publish it directly with GitHub Pages from the repository root or from a docs/ folder.
